# 21. Результаты и порядок передачи

## Обязательные результаты

- Русская спецификация, содержащая требования к модели данных, форматам, UI, импорту/экспорту, синхронизации, тестированию и этапам внедрения.
- JSON Schema и валидируемые примеры Canonical и Human-Readable форматов в `docs/specification/schemas/`.
- Исходник актуальной ER-диаграммы SQLite ([Gaphor](../../assets/OpenIso_DB_ER.gaphor)); диаграмма должна соответствовать текущему описанию раздела 8.5.
- Для изменения схемы БД: последовательные файлы миграций, резервное копирование до миграции и проверка целостности перенесённых данных.
- Для добавления или изменения формата: описание версии, преобразования старых данных и тестовые примеры обратного преобразования, если оно поддерживается.

## Критерии передачи

- Все внутренние ссылки на документы и схемы ведут на существующие файлы.
- Каждый JSON-пример проходит проверку соответствующей JSON Schema.
- Все известные несовместимости, нерешённые решения и ограничения перечислены в соответствующих разделах спецификации; они не скрываются в диаграмме или плане работ.
- Документация описывает согласованное целевое поведение; пользовательские инструкции обновляются отдельно, если меняются действия пользователя.
