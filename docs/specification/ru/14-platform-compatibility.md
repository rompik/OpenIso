# 14. Совместимость и поддерживаемые платформы

## 14.1 Поддерживаемые операционные системы

OpenIso должна работать на следующих операционных системах:

- Windows 10;
- Windows 11;
- Linux.

Конкретные дистрибутивы и минимальные версии Linux в требованиях пока не зафиксированы. Не следует считать поддержку конкретного дистрибутива подтверждённой, пока она не указана в документации выпуска или не проверена в тестировании.

## 14.2 Среда выполнения

- При запуске из исходного кода или установке из PyPI требуется актуальная стабильная серия Python 3.15.x.
- Проект поддерживает только одну актуальную серию Python; тестирование и настройки для устаревших серий отдельно не поддерживаются.
- Для standalone-сборок Windows и Flatpak Python на хосте не требуется: интерпретатор и среда выполнения поставляются способом распространения приложения.
- Установка из PyPI должна предоставлять одинаковый основной функционал на всех поддерживаемых ОС.
- Способ запуска и доступность графического интерфейса должны соответствовать инструкциям установки для выбранной ОС.

## 14.3 Кроссплатформенное поведение

- Основные сценарии редактирования символов, работы с локальной базой SQLite и импорта/экспорта должны сохранять одинаковый результат на Windows и Linux.
- Файловые операции должны корректно обрабатывать пути и разделители, принятые в соответствующей ОС; нельзя предполагать фиксированный абсолютный путь или разделитель каталогов.
- Пользовательские данные и настройки должны размещаться в доступном для записи пользовательском каталоге ОС, а не требовать записи в каталог установки приложения.
- Зависимости от платформенных GUI-диалогов или функций ОС не должны делать базовые пользовательские сценарии недоступными на одной из поддерживаемых ОС.

## 14.4 Проверка совместимости и критерии приёмки

Перед выпуском необходимо проверять запуск и основные пользовательские сценарии как минимум на:

- Windows 10;
- Windows 11;
- Linux в фактически выбранном для проверки окружении.

Проверка платформы должна подтвердить запуск приложения без ошибок, открытие и сохранение данных, доступность основных функций редактора и отсутствие регрессий в поддерживаемых операциях импорта и экспорта. Конкретный перечень сценариев определяется соответствующими функциональными разделами спецификации.

## 14.5 Открытые решения

- Поддерживаемые дистрибутивы и минимальные версии Linux.
- Форматы и каналы поставки standalone-сборок для каждой ОС.
- Минимальные требования к аппаратному обеспечению и графической среде.
