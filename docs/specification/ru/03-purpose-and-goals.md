# 3. Назначение и цели программы

## 3.1 Назначение

OpenIso предназначен для графического создания и редактирования символов SKEY и графики трубопроводных компонентов, применяемых в изометрических схемах.

## 3.2 Цели программы

Программа должна предоставлять пользователю возможность:

1. Создавать и редактировать графику символов с помощью специализированных векторных примитивов.
2. Задавать точки соединения `Arrive`, `Leave`, `Tee` и `Spindle`, определяющие функциональную структуру символа.
3. Импортировать и просматривать символы из файлов ASCII (Intergraph) и IDF (AVEVA).
4. Экспортировать символы в формате ASCII для последующего использования в IsoAlgo.
5. Работать со стандартными категориями SKEY, включая арматуру, фитинги, опоры и приборы.
6. Использовать локализованный интерфейс приложения.
