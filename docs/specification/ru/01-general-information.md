# 1. Общие сведения

## 1.1 Наименование

Полное наименование программы — OpenIso.

## 1.2 Краткая характеристика

OpenIso — графический редактор для создания и управления изометрическими символами трубопроводной арматуры и фитингов (Symbol Keys, SKEY) и их графическим представлением.

## 1.3 Тип программы

Десктопное приложение с графическим интерфейсом.

## 1.4 Лицензия и распространение

- Проект распространяется как программное обеспечение с открытым исходным кодом по лицензии MIT.
- Программа публикуется в PyPI; для установки используется пакет `openiso`.

## 1.5 Поддерживаемые платформы и среда выполнения

- Windows 10, Windows 11 и Linux. Дополнительные требования описаны в разделе [совместимости и поддерживаемых платформ](14-platform-compatibility.md).
- Для установки из PyPI и запуска из исходного кода требуется актуальная стабильная серия Python 3.15.x.
- Запуск установленной программы: `openiso` или `python -m openiso`.

## 1.6 Язык документации

Основным языком документации является русский.
