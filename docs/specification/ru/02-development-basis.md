# 2. Основания для разработки

## 2.1 Практическая потребность

OpenIso предназначен для работы с символами трубопроводных компонентов, используемыми при создании изометрических схем. Программа предоставляет специализированный графический редактор между ручным созданием символов и использованием крупных CAD-систем.

## 2.2 Необходимость обмена данными

Основанием для предусмотренных в программе функций обмена является необходимость работать с символами в форматах существующих инженерных систем:

- импортировать и просматривать символы ASCII формата Intergraph;
- импортировать и просматривать символы IDF формата AVEVA;
- экспортировать символы в ASCII для использования в IsoAlgo

## 2.3 Формат данных ASCII Intergraph

ASCII Intergraph используется для обмена символами трубопроводных компонентов с существующими инженерными системами. Символ рассматривается как единая запись с идентификационными атрибутами и геометрией. Требования к полям, геометрическим данным и преобразованию формата определены в разделах 9.4 и 9.5.
