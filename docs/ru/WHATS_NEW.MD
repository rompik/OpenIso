# Что нового

Полная история пользовательских изменений в OpenIso.

## Версия 0.8.9 (2026-06-04)

### Новое

- Добавлена группа Orientation в панель свойств с четырьмя вариантами режима рисования: None, Always Vertical, All Primary и User Defined.
- В модель Skey, схему базы данных и payload для сохранения/экспорта добавлено новое поле draw_orientation.

### Улучшения

- Переименованы orientation-виджеты в коде в mirror-ориентированные имена для большей ясности.
- Добавлена миграция базы данных, чтобы существующие установки автоматически получили новый столбец draw_orientation.
- Обновлён JSON-предпросмотр символа: элементы geometry теперь выводятся построчно, без многострочного переноса.
- Выполнена сверка типов SKEY End Condition с эталонным списком и зафиксированы текущие расхождения UI/схемы.

## Версия 0.8.8 (2026-06-03)

### Новое

- Экспорт ASCII теперь работает только в одном режиме: Strict Legacy.

### Улучшения

- Обновлено форматирование записей ASC `501` до фиксированного вида в стиле IsoAlgo.
- Обновлено форматирование записей ASC `502` до строгого фиксированного вида со стабильным добиванием нулями.
- Улучшена совместимость экспортируемых ASC-символов с legacy-библиотеками Intergraph/IsoAlgo.

## Версия 0.8.6 (2026-05-28)

### Новое

- Добавлена индикация несохраненного состояния в редакторе.
- Добавлен пользовательский файл настроек и автоматическое создание рабочей папки пользователя.
- Добавлена возможность менять путь к базе символов.

### Улучшения

- Убрана отдельная кнопка сохранения Skey на панели инструментов.

## Версия 0.8.5 (2026-05-26)

### Новое

- Улучшен редактор: добавлена изменяемая ширина панели свойств, синхронизация свойств Skey в реальном времени и компактный JSON-просмотр символа.
- Расширена модель данных символа: добавлены метаданные источника, каталоги релизов и отслеживание версий для синхронизации.
- Добавлены и доработаны инструменты синхронизации каталогов, включая обработку конфликтов.

### Улучшения

- Улучшена система справки: корректное разрешение путей к документации и ресурсам.
- Обновлена локализация для English, Русского и 简体中文.
- Улучшено определение путей к данным и версии как для запуска из исходников, так и для собранного приложения.
