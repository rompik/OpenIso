# Что нового в 0.8.8

Дата релиза: 2026-06-03.

## Новое

- Экспорт ASCII теперь работает только в одном режиме: Strict Legacy.

## Улучшения

- Форматирование записей ASC `501` обновлено до фиксированного вида в стиле IsoAlgo.
- Форматирование записей ASC `502` обновлено до строгого фиксированного вида со стабильным добиванием нулями.
- Улучшена совместимость экспортируемых ASC-символов с legacy-библиотеками Intergraph/IsoAlgo.
