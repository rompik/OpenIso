# What's New in 0.8.8

Release date: 2026-06-03.

## New

- ASCII export now works in one mode only: Strict Legacy.

## Improvements

- ASC `501` record formatting has been updated to IsoAlgo-style fixed-width output.
- ASC `502` record formatting has been updated to strict fixed-width output with deterministic zero-padding.
- Compatibility of exported ASC symbols with legacy Intergraph/IsoAlgo libraries has been improved.
